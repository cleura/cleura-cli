# cleura-cli

`cleura` is the command-line interface for [Cleura Cloud](https://cleura.com/).
Together, `cleura-cli` and `cleura-openstackclient` provide CLI access to all functionality available via the [Cleura Cloud Management Panel](https://cleura.cloud).

## Installation

| Method | Command |
|--------|---------|
| Install script (Linux/macOS) | `curl -fsSL https://raw.githubusercontent.com/cleura/cleura-cli/main/install.sh \| sh` |
| Prebuilt binary | [Releases page](https://github.com/cleura/cleura-cli/releases/latest) |
| Go (1.25+) | `go install github.com/cleura/cleura-cli/cmd/cleura@latest` |
| Homebrew | `brew install cleura/tap/cleura` |
| From a checkout | `make install` |

Full documentation, including command references and guides, is in [docs/](docs/).
